# Shared feature taxonomy

The categories A–K that every research file and the comparison chart use.
Each line lists the features the research looked for in that category.

A. Per-user calling features (DND, call forwarding all/busy/no-answer/unreachable, selective call forwarding/acceptance/rejection, simultaneous ring, sequential ring/find-me, remote office, anonymous call rejection, priority/distinctive ring, call waiting, per-call CLI blocking, call return/*69, last number redial, call trace, speed dial, 3-way calling, hold/transfer, call screening, CLIP/CNAM display, privacy)
B. Business group features (hunt groups and algorithms, auto attendant/IVR, call park, pickup, intercom, paging, BLF/busy lamp, shared call appearance / shared lines / bridged line, executive-assistant (boss/admin), barge-in, whisper, silent monitor, night service / call-flow toggles, schedules/holidays, music on hold, dial-by-name directory, operator console/attendant console, extension dialing across sites)
C. Voicemail and messaging (voicemail, unified messaging, visual voicemail, voicemail to email, transcription, fax to email / email to fax, SMS/MMS, chat/IM, team messaging)
D. Clients and mobility (desktop softphone, mobile app, web client, fixed-mobile convergence / single number reach, presence, click-to-dial, browser extension, call pull/move between devices, hot desking)
E. Conferencing and collaboration (audio conference bridge, meet-me rooms, video meetings, screen share, ad hoc conferencing)
F. Contact center (ACD queues, agent states, wallboards, supervisor tools, callback, skills routing, omnichannel, reporting, WFM)
G. Dialing control and carrier/regulatory (class of service / call restriction, account codes, authorization codes/PINs, E911 / Kari's Law / RAY BAUM'S dispatchable location, STIR/SHAKEN, robocall/spam blocking, CNAM, number porting, toll fraud protection, caller ID per user/group)
H. Recording, analytics and compliance (call recording, CDRs, reporting dashboards, live monitoring, quality (MOS), retention, AI transcription/summaries/sentiment)
I. Integrations and APIs (CRM, Microsoft Teams, Google, REST APIs, webhooks, SSO/SAML/OIDC, directory sync AD/LDAP, Zapier)
J. Administration, provisioning and platform (self-service user portal, admin portal, multi-tenancy, phone auto-provisioning breadth, device management, HA/geo-redundancy, bulk import, backups, security/MFA, updates, central management, white-labeling/reseller hierarchy, billing)
K. Vertical / specialty (hospitality, education/mass notification, healthcare, emergency notification, door phones, wake-up calls, broadcast)
