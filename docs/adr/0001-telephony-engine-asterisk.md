# 0001: Asterisk as the initial telephony engine

**Status:** Accepted (2026-10-12); confirmed by the project owner on 2026-10-12

**Context:** Veyra manages an existing engine rather than implementing SIP.
The candidates were Asterisk and FreeSWITCH. Only one engine will be
implemented initially. The full evaluation is in
[ENGINE_EVALUATION.md](../ENGINE_EVALUATION.md).

**Decision:** Use Asterisk, starting with the 22 LTS series from the Ubuntu
26.04 archive. Control it through ARI on loopback, with AMI disabled.
Configure it through files generated from the database.

**Consequences:** No vendor account is needed to install, and the support
lifecycle is predictable. Multi-tenant isolation must be generated by Veyra
(Asterisk has no native tenant boundary) and tested before activation.
Security updates for the Ubuntu universe package may lag upstream, so a
Veyra-built package will be evaluated in M1. The adapter interface keeps
engine-specific code isolated.
