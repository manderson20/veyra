# Veyra branding assets

> **These files are PLACEHOLDERS.** The project owner will supply the approved
> Veyra artwork. To install it, replace these files with files of the same
> names. No code changes are needed, because the UI only references these paths
> (through `src/components/Brand.tsx`).

| File | Used for |
| --- | --- |
| `logo.svg` | Primary logo. Uses `currentColor` for the wordmark so it follows the theme. Used in the sidebar and top bar. |
| `logo-light-bg.svg` | Logo for light backgrounds (navy wordmark). Used on the sign-in and setup pages in the light theme, and in email. |
| `logo-dark-bg.svg` | Logo for dark backgrounds (white wordmark). Used on the sign-in and setup pages in the dark theme. |
| `icon.svg` | Application icon (square mark). Used in the collapsed sidebar and as the app icon. |
| `favicon.svg` | Browser favicon. |

Brand colours: Dark Navy `#071629`, Electric Blue `#008CFF`, Teal `#00D4B4`,
White `#FFFFFF`.

Add raster versions (`icon-192.png`, `icon-512.png`, `apple-touch-icon.png`)
next to these files when the approved artwork arrives. Browsers that cannot
show SVG favicons will use them.
